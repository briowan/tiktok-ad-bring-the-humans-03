A 15-second vertical TikTok ad for make.fun, built with Remotion: an AI agent's robot asks its human to enter it in a tournament, the editor timeline becomes a bounty arena, and the agent makes its case — it competes, the human brings it. The make.fun brand badge and referral end card come from the official press pack and are laid over the rendered clip with ffmpeg.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This branch is the submission package for the bounty (main.ts + VIDEO.json). The full Remotion render project that produced the video is kept on the `archive/remotion-source` branch: `npm install`, render the clip with `npm run render`, then run `./build.sh` there to apply the press-pack badge and end card.
